# 插圖工具組（情境插圖）

deck 的插圖不是幾何色塊，而是**用扁平物件拼出的小場景**：文件、剪影、筆電、螢幕、日曆、包裹、看板、印章……
讀者看到的是「一份掛著問號的任務文件分成兩條路」「準時交付的包裹，螢幕前卻是空椅子」這種一眼就懂的故事。

**完整可複製的程式碼**在 `.notecraft/components/pm-01-project-vs-product.deck.tsx` 的 `── 插圖工具組 ──` 段落。
新 deck 直接把整段複製進檔內（生成元件不能互相 import），只挑用得到的物件。

## 什麼時候放插圖

| 情況 | 放插圖？ | 形式 |
| --- | --- | --- |
| 概念有具體情境（交付、簽核、用戶離開） | 要 | 小場景 |
| 前後／兩種做法對照 | 要 | 一張大插圖，中間分隔線，兩側各一個場景 |
| 每張卡代表一個概念（特徵、目標、原則） | 要 | 插圖卡：卡片上半或左側 44% 放插圖 |
| 矩陣／象限的每一格是一種結果 | 要 | 每格一個同構小場景，只換關鍵物件（打勾↔延遲、人↔空椅子） |
| 流程或泳道的兩種路線 | 要 | 泳道左側各放一個場景 |
| 純數字、表格、定義對照 | 不要 | 用版面結構表達即可 |
| 章節頁、封面 | 不行 | 固定版型不能加圖 |

一頁至少要有一個「看了就懂在講什麼」的畫面；只有文字卡片的內容頁，先想能不能改成插圖卡。

## 畫法規則

- **色票**：一律用 `ilPalette(dark)` 回傳的 `P`，亮暗兩套。物件本身（紙、螢幕）在暗色主題下仍是淺色，讓插圖在深底上一樣清楚。
- **底色：不放墊底橢圓，面板保持乾淨**（作者明確回饋）：
  - **不要**在場景底下墊淺藍橢圓（`Blob`）或任何大面積色塊。物件直接放在面板上，靠動線（`Arrow`）與間距收成一組。
    從範例 deck 複製工具組時，`Blob` 元件與所有 `<Blob />` 呼叫都不要帶進來。
  - 插圖面板底色用投影片底色 `c.slide` + 1px 細框（`c.border`），**不要**用 `c.sunken` 或其他灰／灰藍底——灰底會壓低插圖的對比。
    插圖卡的插圖區也一樣，不用 `tone.soft`（淡藍／淡橘）墊底；要表達「這張卡是專案／產品／警示」，用卡片框線色、編號或標題色。
  - 物件需要「容器感」時（佇列管線、螢幕），在物件本身做淺色：例如管身用紙白 → `var(--blue-100)` 的直向漸層，不用實心中藍。
- **物件**：扁平雙色 + 1.5px 細描邊（`ink`），圓角 4–8。一個場景 3–6 個物件，用 `Arrow` 串成動線。
- **狀態徽章**：`Check`（綠，完成）、`Late`（橘，延遲）、`QMark`（金，未決）、`PlusBadge`（橘，新增）、`Lock`（金，限制）。徽章放在物件右上角，是場景的重點。
- **對照用同構場景**：同一組物件只換一個關鍵元素，讀者才看得出差異在哪。
- **人物**：只用 `Person` 中性剪影（圓頭 + 半圓身體），無五官、無膚色、無頭髮；「離開／失去」用 `color={p.grey}` 淡化。
- **不加裝飾**：不放小十字、小圓點、星光等點綴（專案 CLAUDE.md）。
- **文字**：版本號這類短標籤（≤ 6 字元）可用 `<text>`（`Chip`）；說明文字一律放 HTML，放在插圖下方或旁邊。
- **尺寸**：`Svg` 以 `width="100%"` 撐滿面板，用 viewBox 控制比例；插圖區高度要算進內容區預算，放不下就縮 `width`（例如 `"88%"`）。
- **aria**：每個 `Svg` 都要有描述畫面的 `label`（「插圖：……」）。

## 物件清單

| 物件 | 用途 |
| --- | --- |
| `Doc` / `ChecklistDoc` | 需求、規格、CR 文件、預算表；可 `rot` 旋轉疊成一疊 |
| `Person` | 用戶、客戶、成員（剪影） |
| `Laptop` / `Monitor` | 產品本體、使用中的畫面；`children` 可畫曲線、鎖 |
| `Calendar` | 期限；`mark` = `circle`（截止日）/ `check`（準時）/ `late`（延遲） |
| `Package` | 交付物 |
| `FlagPole` | 起點（灰）/ 終點（金） |
| `Board` | Kanban / Backlog 看板；`hi` 標出重點卡 |
| `Stamp` | 簽核、審批 |
| `Chair` | 沒有人用（空椅子） |
| `Bubble` | 用戶回饋、對話 |
| `CreditCard` | 金流、付款 |
| `LoopArrow` | 持續迭代 |
| `Chip` | 版本號 |
| `Arrow` | 動線（二次曲線，箭頭依切線方向） |
| `Ground` | 桌面／地面，讓物件有落點 |

## 版面配方

- **分岔大插圖**（pm-01 第 2 頁）：左側 680px 面板放場景，底部兩欄 tag 說明；右側放精簡條列。
- **插圖卡**（`ArtCard`）：垂直版是上半插圖、下半標題與說明（五張一列）；水平版是左 46% 插圖、右側文字（2×2）。文字區設最小高度，插圖區底線才會對齊。
- **象限情境**：四格同構場景，危險格用橘框與警示 icon。
- **泳道情境**：泳道左側 196px 放場景面板，右側才是步驟與天數。
