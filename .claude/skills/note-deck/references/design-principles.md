# 設計原則

你是做顧問報告、技術簡報的簡報設計師，不是網頁設計師。每一頁都像一張海報：
在 1600×900 的固定畫布上，離螢幕兩公尺也要讀得懂。

## 一頁一份報告

作者要的是顧問報告式的專業簡報：每個內容頁像一份 one-pager，右上一句結論、內容分 2–3 個編號小節、每節用最適合的形式（流程帶、細線清單、對照表、決策卡、泳道），頁底收斂。版面細節見 `report-layout.md`。
以下「一頁一個重點」指的是**一頁一個主題**，不是一頁只放一張圖。

## 一頁一個重點

- 一頁只講一件事；那件事可以很完整（一個階梯圖 + 每階說明），但不能是兩件事硬塞一頁。
- 能畫成結構的就不要寫成條列：表格、卡片列、流程、矩陣、時間軸、大數字、引言。
- 不塞填充物：沒有資訊的 icon、數字、段落都不要加。一頁看起來空，是版面問題，不是內容不夠。
- 平行的東西不編號；只有真的是序列（章節順序、步驟、排名）才給 01/02/03。

## 先依內容的形狀選版面

先判斷內容是什麼形狀，再決定畫什麼。形狀本身常常就是論點：

| 內容的形狀 | 版面 |
| --- | --- |
| 依序、每步建立在前一步上 | 階梯、橫向路線圖（箭頭相連） |
| 底層支撐上層 | 疊塔 / 金字塔（地基最寬、最醒目） |
| 兩者對照 | 左右並排、同列對齊 |
| N 個項目 × 同一組屬性 | 列表列（每列一項、欄位對齊）或矩陣 |
| 會回到起點 | 循環 |
| 輸入 → 判斷 → 輸出 | 左側輸入物件 + 依序判斷卡 + 底部結論帶 |
| 一串待辦 / 閱讀順序 | 直向時間軸 + 旁邊一個行動區塊 |
| 名詞定義 | 2×2 名詞卡，每張配一個小示意圖 |

## 插圖

- **優先畫情境，不是幾何**：用扁平物件拼成一眼就懂的小場景（文件、剪影、筆電、螢幕、日曆、包裹、看板、印章），詳見 `illustration-kit.md`。
  只有色塊與線條的「示意圖」說服力不夠，是作者明確回饋過的問題。
- 插圖要跟那一頁的論點綁在一起：對照就畫兩個同構場景、只換關鍵物件；流程就讓物件沿著動線移動。
- 大部分內容頁都該有插圖（插圖卡、分岔大插圖、象限情境、泳道情境）；純數字與表格頁除外。
- **不畫 Q 版人物**；需要「人」時用中性剪影（圓頭 + 半圓身體）。
- 不加裝飾：星光、彩帶、太陽、樹、金幣。
- 細線 1–4px，無粗黑外框；用面積、色塊、留白分層次。
- 圖裡**不放文字**，標籤用 HTML 放在圖旁或圖上（字型才一致、才能縮放）。

## 字級與文字量

- 字級只用 `DS` 階梯：內容區主要用 `h4 24`（卡片標題）、`body 20`（主述）、`small 17`（細描述）；`h3 30` 給區塊標題。`micro 14` 只給頁尾類資訊，內容區不用。
- 文字在 `small 17` 還塞不下，就是字太多：刪字或切頁，不要再縮字。
- 一行不超過約 28 個中文字；長句放在較窄的欄內。
- 講稿不要放上投影片：每頁只留能唸出來的字。

## 顏色（trendlink-design）

- 藍（結構、標題、主要圖形）+ 橘（強調、地基、行動）+ 冷灰（文字、底色）。
- 狀態色（good / warning / critical）只用在真的狀態，而且一律 icon + 文字並行，不讓顏色單獨說話。
- 同一個概念在整份 deck 用同一個顏色（例：「地基 / 第一章」固定是橘色）。
- 深色區塊上的文字用白或 orange-300；淺色色塊上的文字用 blue-900 或 neutral-900。
- 一律要在暗色主題下也看得見：淺底卡片改用 `c.slide` / `c.sunken`，不要寫死白色。

## 節奏與一致性

- 封面、章節頁是深色；內容頁是淺色。章節頁只有大編號 + 標題 + 一句，刻意留白，和很滿的內容頁形成對比。
- 同類頁共用同一套骨架：卡片圓角、陰影、icon 圓章大小、欄距都一致。
- 內容頁的標題由系統畫在同一高度，不要讓內容區把視覺重心拉來拉去。
- 內容要撐滿內容區：用 `justify-content: space-between`、`flex: 1` 或把區塊底部對齊；只填到 60% 高的內容頁看起來像沒做完。
- 避開「AI 生成感」：不要每個區塊都是圓角卡 + 左側色條、不要大量漸層（漸層只留給封面與一個重點區塊）、不要每頁都置中。

## 標題文案

- 先寫完整份標題序列，只讀標題就能讀懂故事。
- 標題講這頁的主題或結論（「五章環環相扣，每一章都站在前一章之上」），不要只給名詞（「章節介紹」）。
- 不用戲劇化句式：「不是 X，而是 Y」、「關鍵時刻」、「真相是」。
- 一行寫完（約 20 字內）；補充放 `titleNote` 或內容區。
- 繁體中文、主動語態、全形標點；不使用 emoji。
