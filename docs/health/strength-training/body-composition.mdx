## 背景

- 男性，身高 175cm，33 歲
- 過去一年：飲食控制、每天晨跑 3km、每週重訓六練（推／拉／腿循環）
- 量測儀器：TANITA MC-980MA

## 從夯到拉評價

::::define{id="fit.physique-review" label="從夯到拉評價"}
**從夯到拉評價**（2026/10 InBody 後的自我評估）：

| 等級 | 項目 |
| :--- | :--- |
| :badge[夯]{variant="danger"} | 減脂成果（脂肪 -14.2kg）、減脂同時增肌 +2.4kg（身體重組）、內臟脂肪 13 → 6 |
| :badge[頂級]{variant="warning"} | 腹肌與側腹可見、紀律（每天晨跑 + 每週六練持續一年）、體型判定升級為標準肌肉型 |
| :badge[人上人]{variant="info"} | 背部寬度與豎脊肌、腿部（雙腿約 12kg）、SMI 10.1 |
| :badge[NPC]{variant="neutral"} | 手臂（單手 3.3kg 是全身最弱環節）、上胸偏平與側三角寬度不足 |
| :badge[拉完了]{variant="neutral" outline} | 兩次對比照的地點、光線、服裝不一致（玩笑性質，下次固定條件拍照） |

總評：一年轉變為「夯」，目前身材在「人上人～頂級」之間。
::::

::::define{id="fit.bia-limit" label="BIA 量測限制"}
:::warning{title="BIA 量測限制"}
**BIA 量測限制**：BIA 受水分與飲食時間影響，實際體脂可能在 12～14%；體內年齡僅供參考。
:::
::::

::::define{id="fit.weight-decision" label="增重速度調整決定"}
